# Unused source art

Nothing in the site, the stylesheet, the scripts or the build tools refers
to these files. They are alternate renders and merch colourways that were
never wired up — mostly crystal-ball variants and two `channeling-light`
product shots.

They are moved here rather than deleted so nothing is lost. If a design
brings one back, move it up to `images/` and re-run:

```bash
python3 tools/optimize_images.py
```

If they are still sitting here unused in a few months, they can go.
